# Noor Traders Hazri (v200)

Staff ki hazri aur salary ka register. GitHub Pages par chalti hai, data Firebase (project `nt-traders`) mein.

- Staff: apne mobile number se login → selfie + location se Check-In / Check-Out, apni hazri, salary, chutti/correction request.
- Malik: Hazri (din / mahina register), Salary (advance, bonus, final, payment), Staff (shamil karna, duty ka waqt, salary settings), requests, smart talash, PDF.

Sab files aik hi folder mein hain (koi sub-folder nahi). Tafseel aur tabdeeliyon ki poori list: `AI_NOTES.txt`.

Test: `npm install` phir `npm test`.
